\# Itinerary Parser



Extract structured travel data from unstructured text using LLM.



\## 🚀 Tech Stack

\- .NET Web API

\- React

\- OpenAI API



\## ✨ Features

\- LLM-based text parsing

\- JSON validation \& normalization

\- Clean UI



\## 🧪 Sample Input

"2 adults from Chennai to Bali between June 10 and June 16 with budget 1.5 lakh INR"



\## ▶️ Run Locally



\### Backend

cd backend

dotnet run



\### Frontend

cd frontend/itinerary-ui

npm install

npm start
